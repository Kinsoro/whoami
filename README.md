## About Me

I am a cybersecurity practitioner in training focused on **Offensive Security**, with a primary specialization in **Infrastructure & Network Penetration Testing** and **Web Exploitation**.

My approach is practical and evidence-driven: enumerate first, understand the attack surface, validate assumptions, exploit responsibly, document the path, and verify the impact.

My current technical direction combines:

- Network and infrastructure penetration testing
- Web application security and exploitation
- Active Directory security assessment
- Windows and Linux privilege escalation
- Pivoting, lateral movement and post-exploitation
- CTF problem solving, with a growing interest in Reverse Engineering
- Security lab engineering and defensive visibility

> **Security work is performed only in authorized labs, CTFs, test environments, and systems where permission has been granted.**

## Methodology

My offensive-security workflow is built around the following lifecycle:

<pre>
Reconnaissance
     ↓
Enumeration
     ↓
Attack Surface Mapping
     ↓
Vulnerability Analysis
     ↓
Initial Access / Exploitation
     ↓
Privilege Escalation
     ↓
Pivoting / Lateral Movement
     ↓
Post-Exploitation
     ↓
Impact Validation
     ↓
Documentation & Write-up
</pre>

The objective is not simply to obtain access. It is to understand **why the attack works**, what trust relationship was abused, what controls failed, and how the path can be reproduced and documented.
